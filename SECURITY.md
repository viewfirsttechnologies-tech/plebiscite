# Security Policy

## Reporting a vulnerability

Do not report vulnerabilities through public GitHub issues and do not include voter information, credentials, registry data, or vote-ledger data in a report.

Report the issue privately to the SOCOTECO II project administrator or designated technical contact. Include a concise description, affected component, steps to reproduce, and recommended mitigation if available.

## Sensitive data

The `secure_storage/` directory is excluded from source control because it may contain MCO registry data and vote records. Treat all such data as confidential and manage it through approved operational procedures.
